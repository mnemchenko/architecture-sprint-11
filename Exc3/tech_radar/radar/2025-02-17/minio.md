We decide to use it as an object storage, because we'd like to keep files inside of our infrastructure (files contain PMI data).

MinIO is a high-performance, S3-compatible object storage platform designed for cloud-native and on-prem deployments. It offers scalability, high availability, and data resiliency, making it ideal for use cases like data lakes, AI/ML workloads, and analytics storage. MinIO integrates with Apache Iceberg, Spark, Presto, and Kubernetes, providing a flexible storage layer for modern data platforms. Currently, we are trialing MinIO to evaluate its performance, reliability, and cost-effectiveness compared to other object storage solutions.
